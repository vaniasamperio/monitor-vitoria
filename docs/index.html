Consulta manual diaria

    Mantenimiento (sin saber programar)

    1. Actualizar ahora: abre esta página de GitHub → botón Run workflow. En 2-3 minutos se refresca.
    2. Añadir o quitar una fuente: edita fuentes.yaml, copia un bloque y cambia nombre y dirección del RSS.
    3. Ajustar las ideas de temas: edita temas.yaml (palabras clave y pistas locales).
    4. Si una fuente sale en rojo varios días, probablemente ha cambiado su dirección: búscala de nuevo y cámbiala en fuentes.yaml.
    Se actualiza solo cada mañana. Los textos y enlaces son de cada fuente original.
